# Cleopatra Gardens Mbuya — 2026 Website Concept

An **unofficial redesign proposal** created by **Habbib Digital Studio** for Cleopatra Gardens Mbuya, Kampala, Uganda.

## Live demo
[Open the website](https://droidremmy76.github.io/cleopatra-gardens-2026/)

## What's included
- Responsive cinematic single-page hospitality website
- Accommodation, gardens, pool, dining, wellness and events highlights
- Mobile navigation, animated reveals and section navigation
- WhatsApp enquiry handoff and directions

## Important
This is an illustrative sales concept, **not** Cleopatra Gardens' official website.
- The photos come from Unsplash as placeholders and are **not verified photographs of Cleopatra Gardens**.
- Brand colours and wording are conceptual.
- No live reservation system is connected: the enquiry form opens a prefilled WhatsApp message.
- Confirm venue phone numbers, room prices, amenities, address and operating hours with management before launch.
